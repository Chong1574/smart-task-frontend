# Reglas del Proyecto: Task-Manager

## Git Workflow
En este proyecto, siempre realiza el `git add`, `git commit` y `git push` automáticamente después de realizar modificaciones en el código. No es necesario pedirle permiso al usuario antes de hacer el commit o el push. Utiliza mensajes de commit descriptivos y semánticos (ej. `feat:`, `fix:`, `refactor:`).
